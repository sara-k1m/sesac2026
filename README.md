# ☁️ SeSAC Cloud Data Engineering

**새싹(SeSAC) 클라우드 데이터 엔지니어링 과정**에서 학습하고 실습하며 진행한 프로젝트와 결과물을 정리한 Repository입니다.

Python과 SQL을 기반으로 데이터 처리 및 분석 역량을 쌓고,
데이터 엔지니어링과 클라우드 환경에 대한 이해를 넓혀가고 있습니다.

---

## 📚 About the Course

**SeSAC 클라우드 데이터 엔지니어링 과정**

> 데이터 수집부터 처리, 분석, 그리고 클라우드 기반 데이터 파이프라인까지
> 데이터 엔지니어링 전반의 기술과 실무 과정을 학습합니다.

### 주요 학습 분야

* 🐍 **Python**
* 🗃️ **SQL & Database**
* 📊 **Data Analysis**

* ☁️ **Cloud Engineering**

## 🌱 Growth

단순히 기술을 학습하는 것에서 그치지 않고,

**데이터를 수집하고 → 처리하고 → 분석하고 → 활용하는**

전체 과정을 직접 경험하는 것을 목표로 하고 있습니다.

앞으로 다양한 실습과 프로젝트를 추가하며
데이터 엔지니어링과 클라우드 분야의 실무 역량을 꾸준히 확장해 나갈 예정입니다.
