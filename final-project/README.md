## 1. Project Overview

### 분석 배경

금리는 주택 임대차 시장의 주요 거시경제 변수 중 하나입니다.

금리가 하락하면 대출 부담이 감소하면서 주택 수요와 임대차 시장의 구조가 변화할 수 있고, 반대로 금리가 상승하면 주택 보유 및 자금 조달 비용 증가와 함께 전세에서 월세로의 전환이 나타날 가능성이 있습니다.

이에 다음과 같은 질문에서 분석을 시작했습니다.

> **금리 변화는 실제 서울시 월세 시장의 가격 변화로 이어지는가?**

또한 서울은 자치구별 주거환경과 입지 특성이 크게 다르기 때문에,

> **금리 변화에 따른 월세 가격의 반응은 자치구별로 차이가 있는가?**

를 함께 검증했습니다.

분석 결과를 실제 주거 의사결정에 활용할 수 있도록 **2025년 월세 실거래 데이터와 지하철 접근성 정보를 결합한 Streamlit 대시보드**도 구축했습니다.

## 5. Data Preprocessing

### 5.1 원본 데이터 정제

월세 시장 분석에 적합한 데이터셋을 구축하기 위해 다음과 같은 전처리를 수행했습니다.

* 연도별 원본 데이터 통합
* `전월세구분 == "월세"` 데이터만 추출
* 2025년 중복 거래 제거
* 주소 생성이 불가능한 데이터 제거
* 임대면적 10㎡ 미만 거래 제외
* 임대료 0원 거래 제외
* 극단적인 단위면적당 월세 거래 제거

### 5.2 주소 생성

다음 정보를 조합하여 거래 주소를 생성했습니다.

```text
자치구명 + 법정동명 + 본번 + 부번
```

### 5.3 지오코딩

2025년 데이터를 대상으로 거래 주소를 좌표 데이터로 변환했습니다.

```text
고유 주소 추출
    ↓
Kakao Local API
    ↓ 실패
VWorld 주소 API
    ↓ 실패
Google Geocoding API
    ↓
최종 좌표 데이터 구축
```

주소 단위로 지오코딩하여 API 호출 횟수를 줄였으며, 실패 데이터에 대해서는 단계적으로 다른 API를 적용하여 좌표 확보율을 높였습니다.

### 5.4 파생변수 생성

| 변수         | 생성 방법                 |
| ---------- | --------------------- |
| `address`  | 자치구명 + 법정동명 + 본번 + 부번 |
| `년월`       | 계약일에서 연-월 추출          |
| `월세_㎡당`    | 임대료 ÷ 임대면적            |
| `금리변화`     | 금리의 전월 대비 변화량         |
| `월세변화`     | 월세의 전월 대비 변화량         |
| `보증금변화`    | 보증금의 전월 대비 변화량        |
| 거래건수       | 월별 거래 건수 집계           |
| 월세 평균/중앙값  | 월별 집계                 |
| 보증금 평균/중앙값 | 월별 집계                 |
| 최근접역       | 거래 좌표 기준 가장 가까운 지하철역  |
| 최근접역 거리    | 거래 좌표와 지하철역 좌표 간 거리   |
| 거리구간       | 최근접역 거리를 5개 구간으로 구분   |

지하철 접근성은 다음과 같이 구간화했습니다.

```text
250m 이하
250~500m
500m~750m
750m~1.5km
1.5km 초과
```

## 6. Exploratory Data Analysis

### 6.1 자치구별 단위면적당 월세

2025년 데이터를 기준으로 자치구별 단위면적당 월세를 비교한 결과, **자치구에 따라 상당한 가격 차이**가 나타났습니다.

* 중구: 약 **2.3만원/㎡**
* 양천구: 약 **1.0만원/㎡**
* 최상위와 최하위 자치구 간 약 **2배 이상의 격차**

강남구와 마포구 등 업무 및 상업 중심 지역은 상대적으로 높은 단위면적당 월세를 보였으며, 강북구, 노원구, 도봉구, 중랑구 등 일부 외곽 주거지역은 상대적으로 낮은 수준을 나타냈습니다.

이를 통해 서울시 월세 시장에는 **지역별 구조적 차이**가 존재함을 확인했습니다.

## 7. Hypothesis Testing

### H1. 정부대출금리 변동은 단위면적당 월세 및 보증금 변동에 영향을 미칠 것이다.

금리 변화가 월세 및 보증금 변화와 어떤 관계를 갖는지 확인하기 위해 월별 데이터를 전월 대비 변화량으로 변환한 후 회귀분석을 수행했습니다.

또한 시간에 따른 자연스러운 가격 변화를 금리 변화와 구분하기 위해 **시간 추세 변수**를 추가하여 통제했습니다.

#### 분석 결과

> **정부대출금리가 1%p 상승할 때 단위면적당 월세는 평균적으로 약 0.19만원 상승하는 관계가 나타났습니다.**

시간 추세를 통제한 이후에도 계수의 크기와 통계적 유의성이 크게 변하지 않아, 단순한 시간 추세만으로 설명되는 관계는 아니라는 결과를 얻었습니다.

반면 보증금에서는 금리 변화와의 뚜렷한 관계가 확인되지 않았습니다.

### H2. 정부대출금리 변동에 따른 월세 임대료 변화는 서울의 자치구에 따라 차이가 있을 것이다.

자치구마다 존재하는 기본적인 월세 수준의 차이를 통제하기 위해 자치구를 범주형 변수로 처리하고, 다음과 같은 상호작용항을 포함했습니다.

```text
금리변화 × 자치구
```

이후 25개 자치구의 상호작용항을 동시에 검정하는 **Wald Test**를 수행했습니다.

#### 분석 결과

> **금리 변화에 따른 월세 변화는 자치구별로 통계적으로 유의한 차이가 나타났습니다.**
>
> `p = 0.0158 < 0.05`

즉, 서울 전체를 하나의 시장으로 보는 것보다 **지역별로 금리 민감도가 다를 수 있음**을 확인했습니다.

## 8. Key Findings

### ① 금리 상승과 월세 상승의 양(+)의 관계

정부대출금리가 상승할 때 단위면적당 월세도 상승하는 통계적으로 유의한 관계가 나타났습니다.

특히 2022년 이후 금리가 급격하게 상승한 시기에 월세 역시 상승하는 패턴이 관찰되었습니다.

### ② 보증금은 금리와 뚜렷한 관계가 확인되지 않음

보증금은 금리 변화와 일정한 방향으로 움직이는 패턴이 명확하지 않았습니다.

따라서 이번 분석에서는 **금리의 영향이 보증금보다 월세에서 더 뚜렷하게 나타났습니다.**

### ③ 자치구별 금리 민감도 차이

금리 변화가 월세에 미치는 영향은 25개 자치구에서 동일하지 않았습니다.

이는 서울의 월세 시장이 단순히 금리라는 하나의 거시경제 변수만으로 설명되기보다 **지역별 주거환경과 시장 특성의 영향을 함께 받는다는 점**을 보여줍니다.

### ④ 월세 시장의 지역적 격차

2025년 자치구별 단위면적당 월세를 비교한 결과, 지역에 따라 약 2배 이상의 가격 차이가 확인되었습니다.

## 12. Limitations & Future Work

### 한계

#### 1. 낮은 설명력

회귀모형의 `R² = 0.047`로 나타나 **금리 변화만으로 월세 변동의 상당 부분을 설명하기에는 한계**가 있습니다.

#### 2. 인과관계 검증의 한계

금리 변화와 월세 변화 사이의 통계적으로 유의한 관계는 확인했지만,

> **금리 상승이 월세 상승을 직접적으로 유발했다고 단정할 수는 없습니다.**

본 분석은 관측자료를 기반으로 한 회귀분석이므로 인과관계를 확정하기 위해서는 추가적인 식별 전략이 필요합니다.

#### 3. 충분한 통제변수 확보의 한계

주택 공급량, 지역별 수요, 주택 유형, 건축연도, 면적 등 월세에 영향을 줄 수 있는 다양한 요인을 충분히 통제하지 못했습니다.

#### 4. 자치구별 차이의 원인 분석 부족

자치구별 금리 민감도의 차이는 확인했지만, **어떤 지역 특성이 이러한 차이를 발생시키는지**까지는 분석하지 못했습니다.

### 향후 분석

* 지하철 접근성과 금리의 상호작용 분석
* 자치구별 금리 민감도와 지역 특성 간 관계 분석
* 주택 공급량 및 지역별 수요 변수 추가
* 주택 유형 및 건축연도 등 주택 특성 통제
* 금리 변화의 시차(Lag)를 고려한 동태적 분석
* 최신 실거래 데이터 자동 업데이트
* 지속적으로 갱신되는 서울 주거시장 분석 대시보드로 확장

## 13. 활용 방안

### 주거 의사결정 지원

자치구, 지하철 노선 및 역, 역까지의 거리, 월세와 보증금 등의 조건을 기준으로 원하는 주거지역을 비교할 수 있습니다.

### 역세권 주거비 비교

지하철 접근성과 임대료 데이터를 결합하여 **교통 접근성에 따른 주거비 차이**를 직관적으로 확인할 수 있습니다.

### 금리 변화에 따른 시장 흐름 파악

금리 변동과 월세 변화의 관계를 통해 금리 환경 변화가 임대시장에 미치는 영향을 탐색할 수 있습니다.

### 데이터 기반 지역 탐색

지도와 추천 랭킹을 활용하여 사용자가 **가격과 입지 조건을 함께 고려한 주거지역 탐색**을 할 수 있도록 지원합니다.
